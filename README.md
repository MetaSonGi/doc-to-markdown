# 📄 문서 → 마크다운 변환기 (doc-to-markdown)

MarkItDown 아이디어의 브라우저판 — 문서를 마크다운으로 변환하는 웹앱.
100% 브라우저에서 동작하며, 파일이 서버로 전송되지 않습니다.

## 사용법

1. **파일 선택**: 파일을 드래그앤드롭하거나 클릭해서 선택 (여러 파일 일괄 변환 가능)
2. **옵션**: 메타데이터 헤더 추가 / HTML 변환 시 목차(TOC) 생성
3. **결과 확인**: 미리보기 탭과 마크다운 원본 탭 전환
4. **📋 복사** 또는 **⬇ .md 다운로드** (`파일명_변환.md`)

## 지원 형식

| 형식 | 변환 방식 |
|------|----------|
| HTML (.html/.htm) | h1–h6, p, ul/ol, 링크·이미지, strong/em, code/pre, blockquote, table, hr 변환. script/style/nav 등은 제거. 목차(TOC) 생성 옵션 |
| CSV (.csv) | 첫 행을 헤더로 마크다운 표 생성. 따옴표·콤마·개행 포함 셀 처리, 파이프 이스케이프 |
| JSON (.json) | 중첩 구조를 들여쓰기 리스트로 변환. 너무 크면 코드블록으로 폴백 |
| TXT (.txt) | 빈 줄 기준 문단 분리, `-`/`1.` 리스트 자동 감지, 짧은 독립 줄은 `##` 제목으로 처리 |
| XML (.xml) | 태그 구조를 중첩 리스트로 표현 (속성 포함) |
| MD (.md) | 정리 — 연속 빈 줄 축소, 줄 끝 공백 제거 |

## 지원하지 않는 형식

- **PDF · DOCX · PPTX · XLSX** — 바이너리 문서는 브라우저 단독으로 파싱할 수 없어 지원하지 않습니다.
  (해당 파일 선택 시 안내 메시지가 표시됩니다)

## 기술

- 단일 `index.html` (CSS/JS 전부 인라인), 외부 의존성 0 (CDN 없음, 시스템 폰트만)
- HTML/XML 파싱: 브라우저 내장 `DOMParser` 사용
- CSV/JSON/TXT 파서: 직접 구현 (라이브러리 없음)
- 미리보기 렌더러: 직접 구현한 경량 마크다운 렌더러
- 미리보기의 `javascript:` URL은 차단됩니다

## 실행

`index.html`을 브라우저에서 열거나 GitHub Pages로 배포하면 바로 사용할 수 있습니다.
